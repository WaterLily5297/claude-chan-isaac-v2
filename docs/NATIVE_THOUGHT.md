# Native Thought attack adapters

This document describes the integrated normal DeepSeek Thought adapters in `scripts/characters/thought_attacks.lua`. The current installed manual-test checkpoint is `220d542`, including PRs #89 and #90. BACKLOG-LASER-INIT-01 is a later source correction and is not installed. See HANDOFF.md and the local receipt for exact source/runtime evidence. Agent-run engine testing remains deferred; no engine acceptance is claimed. Existing 0.9x base damage and Rice meal rules remain in place, and attacks use native weapon entities.

## Current source rules

| Native attack | Observation | Thought rule |
|---|---|---|
| Ordinary player tear | POST_FIRE_TEAR | One same-frame volley, snapshot multiplier for the tear's flight |
| Single-hit laser | First POST_LASER_UPDATE with positive damage | One same-frame volley, snapshot multiplier |
| Released circle laser, without the Ludovico flag | First laser update | One snapshot for the released ring |
| Repeated-hit beam, including Brimstone | Laser updates | Shared six-gameplay-update windows |
| Ludovico tear or circle beam | Tear/laser updates and native HasTearFlags | Shared six-update windows; continuing attacks block idle Thought recharge |
| Flying knife | First update observing IsFlying | Snapshot once per throw; remove the factor when it returns |
| Dr. Fetus bomb | First positive ExplosionDamage update with IsFetus | Snapshot one same-frame volley; do not affect ordinary placed bombs |
| Delayed burst (Cursed Eye, multi-frame volleys) | Any discrete attack above | Shares the paid volley until the native cycle could fire again: floor(MaxFireDelay) updates, cap 15; pause does not age it; continuous attacks never join it |
| Melee swing (Forgotten's club, Spirit Sword and similar) | First POST_KNIFE_UPDATE of a `KnifeSubType.CLUB_HITBOX` knife | Snapshot once per hitbox; owner is the held weapon knife's player |
| Epic Fetus rocket | First POST_EFFECT_UPDATE of an `EffectVariant.ROCKET` spawned by the player or its target marker | Snapshot once per rocket using the shared discrete-volley payment; attributed explosion damage is cancelled and re-dealt once at its factor, never to players |
| Incubus / Twisted Pair tear | First POST_TEAR_UPDATE of a tear spawned by that familiar | Uses the owner's current paid discrete volley (`Peek`), never pays; judged once; other familiars stay native |

Player attack adapters require a directly identified player, with the held-weapon and rocket-target links described above. A familiar spawner does not fall back to its player to bill that player. Incubus and Twisted Pair tears are the explicit non-paying exception: they can inherit an existing paid volley through `Peek`. Parent-only attribution is accepted only when that parent itself is a player. Reflected-laser ancestry, detached reflected beams and bomb-child ancestry cannot pay again. This does not establish every familiar or synergy's attribution.

The repeated-hit beam rule is a balance choice: only the initial 0.2-second window receives stored Thought, unless a later Rice reward supplies more Thought. A finite Brimstone beam is also a repeated-hit beam under this rule. It is not a promise of 2x damage for the entire beam lifetime. An ongoing controlled attack cannot recharge itself by releasing the aim buttons. Ordinary travelling tears and a thrown knife do not prevent idle recharge solely by remaining alive.

Six-update windows share one per-player payment and multiplier. They preserve remaining time across continue, pause without advancing, and expire without regenerating Thought from their own activity. A window is a saved scalar budget, not a saved entity reference. Room changes discard the room's window. Character changes, replacement identities and death reset it alongside the Rice economy. Moving the same live pointer/seed between slots preserves its progress and clock; [O6 identity coverage](O6_RICE_MEAL_IDENTITY.md) distinguishes this from replacement and tests supplied knife-exit cleanup. Older Rice saves without window fields start with no active window.

## Damage composition and lifecycle

Transient entity records remember the unboosted value and the last value written. An unchanged write is never multiplied again. A different positive value is treated as a fresh unboosted value from the engine or another writer. This is an explicit integration assumption: arbitrary mods that instead multiply the already-boosted value, or coincidentally write the same numeric value as the prior result, cannot be distinguished by inspecting a shared scalar. Do not claim universal cross-mod damage compatibility from these tests.

1M Context obtains its decay baseline through `ThoughtAttacks.BaseDamage`; ordinary released projectiles retain their resolved flight multiplier in that baseline. Since PR #76 merged as `5bbe9e4`, tears carrying `TEAR_LUDOVICO` skip context rot. That exemption does not change Thought's six-update budget or the paid-attack resource rules. Its native weapon interactions still need engine acceptance. Swarm/tainted raw forks are tagged as derived. A continuous fork refers to its parent's transient factor, does not pay or mark the player as firing, and cannot retain an expired window when updated first. When a fresh window begins, a child updated before its parent can receive the parent's new factor one update later; actual collision ordering remains an engine case.

Temporary continuous/knife factors are removed on return, room change and pre-exit cleanup only if the field still matches this module's last write. Another writer's changed value is not overwritten during cleanup. Cleanup also reaches freshly copied children before their first update. EntityPtr references and callback records stay transient; only scalar window count/factor are stored with Rice state. Actual game save order, continued entities and engine damage refreshes must be observed before acceptance.

These adapters do not change player types, player sprites, tears' visual scale, tear flags, color, steering, collision classes, flight arcs, bomb radius or weapon selection. They do not replace the native weapon entities. Epic Fetus is a damage-dispatch exception: `MC_ENTITY_TAKE_DMG` cancels a rocket-attributed explosion hit and calls `TakeDamage` once at the stored factor, preserving the supplied flags, source and countdown. A recursion guard prevents this module from re-dealing that call again; player targets and a factor of 1 bypass it. Other damage callbacks can still observe the re-dealt event, so native attribution and callback interactions need engine testing. Existing native attacks are not deleted by the food lockout; charged releases and programmatic attacks during a meal remain unverified.

## Offline evidence and remaining engine matrix

Historical native-Thought checkpoint: `tests/native_thought_test.lua` invoked the real Rice, shared food, raw fork and 1M Context modules. Against `e8639cb`'s Rice module its first laser assertion failed. That candidate passed native entity callback fixtures for shared volleys, six-update expiry, duplicate calls, pause, partial-window continue, positive-damage initialization, direct/co-op ownership, knife return/rethrow, ordinary-bomb exclusion, parent/child update order, immediate-exit cleanup, parent removal, modeled engine base refresh and Context decay. Its full gate contained 63 Lua files, five XML files and seventeen stub suites. These are historical counts, not the current repository totals; current gate evidence belongs in HANDOFF.md. All of these fixtures model entity callbacks and do not establish engine acceptance.

When game testing resumes, record exact source/runtime versions and test these cases independently:

- Technology, Technology 2, Brimstone, Technology X and Ludovico, including mixed pickups: confirm actual OneHit, circle, parent and high-bit flag behavior, release timing and damage dealt. Do not infer type classification from the displayed sprite alone.
- Mom's Knife: charge, release, return, contact, multiple knives and room transitions. Test knife+Brimstone and knife+Ludovico separately.
- Dr. Fetus: ordinary and multi-shot bombs, bomb synergies, child bombs, native explosion damage/radius and player attribution.
- Ludovico and repeated beams with Swarm and 1M Context, in both update orders where observable. Confirm Ludovico tears remain exempt from context rot while ordinary tears still decay; Thought bonuses must still expire without permanent amplification, duplicate payment or visual/steering replacement.
- Pause and save/continue in each of the six window positions. Confirm remaining time, unboosted serialization, no permanent factor and no lost/duplicated Rice reward. Test exit during a flying knife separately; entity persistence is not modeled by the stub.
- Epic Fetus (with and without Dr. Fetus or Brimstone), the Forgotten's club, Spirit Sword, Cursed Eye, Incubus and Twisted Pair: damage dealt, single payment per attack and no permanent factor.
- Reactions Port Pack, native transformations/size/flight items and other mods that write projectile damage. Existing costume and hurt-pose acceptance remains open.

Epic Fetus rockets, melee swing hitboxes, delayed bursts and Incubus/Twisted Pair tears now have source adapters (`tests/thought_adapters_test.lua`). They are not engine-accepted: confirm that each swing spawns a fresh hitbox whose CollisionDamage is the swing damage, that rocket explosions name the rocket as their damage source, that mimic familiars fire within the owner's firing cycle, and that Cursed Eye and similar bursts fall inside floor(MaxFireDelay). If the rocket source is the player instead, the adapter pays without boosting; record that case. Familiar lasers, knives and bombs, and all other familiars, remain native under the Thought adapters.

Normal DeepSeek Thought is separate from the allowance service in `scripts/characters/paid_attacks.lua`. Normal Claude usage, tainted Claude Quota, tainted GPT Full Send Credits and Opus Mode combine their tear/laser-start/Fetus callbacks with that observer for knife throws, melee hitboxes, Epic Fetus rockets and further six-frame windows of held repeated-hit beams or firing Ludovico tears. Each observer has its own transient entity marker (PR #78), so an earlier subscriber cannot consume another subscriber's event. The observer ignores familiar-owned weapons, child lasers and tagged derived Ludovico tears. DETACHED-LASER-01 retains child identity seen at init/update in entity-local data, before pause/age filters, so cleared Parent links cannot consume another observer window. Fresh entities remain independent, including reused pointer hashes. This is not a blanket guarantee about every weapon initialization callback or synergy.

PR #82 separately excludes backlog `FireDerived` helpers from early Opus tear billing through a transient scope on their owner, before later callbacks can mark the tear. Please Retry and One More Finger use that path; marked derived tears also bypass Opus billing. The following normal shot and another player's normal shot still count. Summary Stapler intentionally keeps normal-shot billing, and tainted Llama's separate `FireTear` helper is outside this correction. Native callback timing and helper interactions remain pending in TESTING.md OPUS-DERIVED-01.

LLAMA-HELPER-01 routes tainted Llama's stationary helper through that same initialized `FireDerived` service. Its native tear arguments, position, aiming, 0.5x damage multiplier and duration are preserved. The helper is excluded from Opus billing, attack primes and backlog paid-attack item triggers. This is a separate source follow-up to PR #82; native helper effects, Swarm, weapon replacements and co-op remain acceptance cases in TESTING.md.

Tainted DeepSeek also uses this observer. Paid tear volleys produce two half-damage forks; paid non-tear attacks receive a 1.3x off-peak boost at the phase's Compute price, with the same-frame payment shared across weapons. Its separate damage callback re-deals attributed non-player damage, checks the active beam window and excludes a resting knife. PEAK-CHILD-LASER-01 shares the parent laser's resolved decision with validated children, including subsequent paid/unpaid windows, without renewed expiry or payment. Detached children keep their classification; an optional subscriber exclusion prevents them consuming Peak's next observer window. DETACHED-LASER-01 adds retained init/update classification for all subscribers; Peak's optional exclusion also handles children first recognized by damage. Both corrections are installed in `220d542` but not engine-accepted. BACKLOG-LASER-INIT-01 separately observes child init for backlog primes and attack identity; this later correction is not installed. A child whose unresolved ancestry disappears remains unboosted and cannot invent a parent payment. This does not prove actual explosion attribution, beam timing or compatibility with other damage callbacks; see TESTING.md for the every-weapon billing and tainted DeepSeek cases.
