# Item reference

Generated by `tools/item_reference.lua` from `content/items.xml`, `content/pocketitems.xml` and the English text in `scripts/eid.lua`. Do not edit by hand; run `lua5.4 tools/item_reference.lua .` after changing an item.

The pickup line is what the game shows when you pick the item up. The effect column is the External Item Descriptions (EID) text, shown in game when EID is installed. Effects describe the current source; most have not been verified in the engine yet (see docs/TESTING.md).
